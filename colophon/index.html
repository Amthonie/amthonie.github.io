About this site

This website is built to be lightweight, transparent, and fully under my control. It uses no tracking, and only minimal, privacy‑friendly analytics via Umami Cloud (opens in a new tab). It sets no cookies either — with one optional exception: switch on “remember my tinkering” on the Melodies page and it keeps the melody you’re editing on your own device, nothing more.

Every page is hand‑crafted in HTML, CSS and a little vanilla JavaScript — styled with Tailwind and compiled to static CSS, with no client‑side frameworks. The full source is public on GitHub (opens in a new tab), and the site itself is hosted on GitHub Pages.

All photographs are my own unless noted otherwise, and all illustrations are created by me with the assistance of AI tools.

Built with

A handful of small open-source libraries do some of the heavy lifting — all self‑hosted, with no third‑party CDNs:

  • PhotoSwipe (opens in a new tab) — the image lightbox, by Dmitry Semenov (MIT).
  • Meteocons (opens in a new tab) — the animated weather icons, by Bas Milius (MIT).
  • rtttl‑play (opens in a new tab) — the melody player on the Melodies page, by Adam Rahwane (MIT).
